# 职言 · 职场专业英语 H5 原型

面向职场技术岗（首个垂直场景：新能源电池热管理工程师）的专业英语学习原型。

- 450 个专业词（9 大类，含释义/例句/搭配/易混辨析/记忆点），按 30 个真实工作专题成包（每包 14~16 词 + 1 篇工程师发言稿）
- 每日一课（无需设目标）：整包新词 首看 → 双向题（对错均给解析）→ 朗读当篇发言稿（逐词点查 + 全文 TTS + 三档自评）→ 错题加权报告 + 薄弱点分析 → 自动排入次日复习（上限 8）
- 纯客户端：进度存 localStorage，可生成"备份码"跨设备恢复
- 手机端访问体验最佳；发音使用系统 TTS

## 本地运行

```bash
python3 -m http.server 8848   # 在本目录
# 浏览器打开 http://localhost:8848
```

## 测试

```bash
jsc test_core.js   # 核心算法模拟测试（学习流程/主题包/权重/备份码等），node 亦可
# UI 全链路点击测试：Chrome 无头打开 test_ui.html（普通日）与 test_ui_article.html（预置进度验证朗读日）
```

`core.js` 为平台无关纯函数层，后续将原样平移至微信小程序。
