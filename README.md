# 职言 · 职场专业英语 H5 原型

面向职场技术岗（首个垂直场景：新能源电池热管理工程师）的专业英语学习原型。

- 450 个专业词（9 大类，含释义/例句/搭配/易混辨析/记忆点）+ 50 个海外工作场景句（逐词解析 + 句式模板）
- 每日闭环：设目标 → 看词选义 → 看义选词（对错均给解析）→ 句子朗读 + 逐词点查 + 三档自评 → 错题加权报告 + 薄弱点分析 → 自动排入次日复习
- 纯客户端：进度存 localStorage，可生成"备份码"跨设备恢复
- 手机端访问体验最佳；发音使用系统 TTS

## 本地运行

```bash
python3 -m http.server 8848   # 在本目录
# 浏览器打开 http://localhost:8848
```

## 测试

```bash
jsc test_core.js   # 核心算法模拟测试（5天学习流程/权重/备份码等），node 亦可
# UI 全链路点击测试：Chrome 无头打开 test_ui.html
```

`core.js` 为平台无关纯函数层，后续将原样平移至微信小程序。
